# 机器视觉 Demo：工件尺寸测量 + 缺陷检测

用 Python + OpenCV 做的小项目，对应机器视觉 / AOI 岗位面试。

## 它做了什么

1. 生成两张合成工件图（正常件 / 带划痕和污点的缺陷件）
2. 尺寸测量：用右上角 50mm 标准块标定像素比例，量出工件 200x100mm、孔直径 30mm
3. 缺陷检测：用“标准件 vs 待检件”模板差分，框出划痕和污点

## 怎么运行

双击 `run_vision.bat`，或者：

```powershell
cd D:\codex\11-AI学习\day03\vision_demo
python main.py
```

运行完看 `output/` 里两张结果图。

## 代码结构（面试要能讲）

| 文件 | 作用 |
| --- | --- |
| make_samples.py | 用 OpenCV 画合成工件，生成 good.png / defect.png |
| measure.py | 标定像素比例，测工件长宽和孔直径 |
| detect_defect.py | 模板差分 + 面积过滤，找划痕和污点 |
| common.py | 中文路径兼容的图片读写 |

## 面试怎么讲

话术模板：

> 我用 OpenCV 做过一个机器视觉小 Demo：用标准块做像素-毫米标定，实现工件尺寸测量；
