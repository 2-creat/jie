# AI 学习仓库（小杰）

每天在这里提交学习内容，用 Git 记录成长轨迹。

## 仓库结构

```text
11-AI学习/
├── README.md            # 本文件
├── 学习日志.md           # 每日打卡：学了什么、跑通没
└── day01/
    ├── python_quiz.py   # Python 查漏补缺自测（跑一遍看分数）
    ├── api_hello.py     # 大模型 API 第一个脚本
    ├── api_key_config.md# DeepSeek / 通义 / 智谱 注册步骤
    └── git_cheatsheet.md# 每天提交的 Git 命令
```

## 第一周任务

1. 跑通 `python_quiz.py`，不会的题补完。
2. 注册 3 个国内大模型平台并拿到 API Key，按 `api_key_config.md` 操作。
3. 用 `api_hello.py` 跑通“输入文字返回回答”。
4. 每天做完学习后用 `git_cheatsheet.md` 的命令提交一次。
5. 开始看 SQL 与 AI 基础概念（资源见 05-文档模板/AI学习路径）。

## 每日提交口诀

```bash
git status
git add .
git commit -m "Day 01: 跑通 Python 自测与大模型 API"
```

等 GitHub 注册好后，再关联远程仓库并 `git push`。
